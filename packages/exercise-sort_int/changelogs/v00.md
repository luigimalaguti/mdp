### To code

```c
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

int compare_int32(const void *pointer_a, const void *pointer_b) {
    int32_t number_a = *(int32_t *)pointer_a;
    int32_t number_b = *(int32_t *)pointer_b;
    return (number_a > number_b) - (number_a < number_b);
}

int main(int argc, char **argv) {
    if (argc != 3) {
        printf("Usage: %s <input_file> <output_file>\n", argv[0]);
        return EXIT_FAILURE;
    }

    const char *input_filename = argv[1];
    const char *output_filename = argv[2];

    FILE *input_file = fopen(input_filename, "r");
    if (input_file == NULL) {
        printf("Error: Could not open file %s\n", input_filename);
        return EXIT_FAILURE;
    }

    size_t size = 0;
    size_t capacity = 0;
    int32_t *data = NULL;

    int32_t number;
    while (fscanf(input_file, "%d", &number) == 1) {
        if (size >= capacity) {
            size_t temp_capacity = capacity == 0 ? 1 : capacity * 2;
            int32_t *temp_data = realloc(data, temp_capacity * sizeof(int32_t));
            data = temp_data;
            capacity = temp_capacity;
        }
        data[size] = number;
        size++;
    }
    fclose(input_file);

    qsort(data, size, sizeof(int32_t), compare_int32);

    FILE *output_file = fopen(output_filename, "w");
    if (output_file == NULL) {
        free(data);
        printf("Error: Could not open file %s\n", output_filename);
        return EXIT_FAILURE;
    }

    for (size_t index = 0; index < size; index++) {
        fprintf(output_file, "%d\n", data[index]);
    }
    fclose(output_file);

    free(data);
    return EXIT_SUCCESS;
}
```

## Details

### Impostazione dell'esercizio

Il testo dell'esercizio richiede di creare un programma che possa essere eseguito secondo la seguente sintassi da terminale:

```bash
$ sort_int <filein.txt> <fileout.txt>
```

Quindi il `main` dovrà come prima cosa controllare il numero di argomenti passati alla riga di comando. In secondo luogo, dovrà aprire il file di input e output. Nel caso dovessero esserci errori in uno di qualsiasi di questi passaggi, il programma dovrà stampare un messaggio di errore e terminare l'esecuzione.

```c
// ...

int main(int argc, char **argv) {
    if (argc != 3) {
        printf("Usage: %s <input_file> <output_file>\n", argv[0]);
        return EXIT_FAILURE;
    }

    const char *input_filename = argv[1];
    const char *output_filename = argv[2];

    FILE *input_file = fopen(input_filename, "r");
    if (input_file == NULL) {
        printf("Error: Could not open file %s\n", input_filename);
        return EXIT_FAILURE;
    }
    // ...
    fclose(input_file);

    // ...

    FILE *output_file = fopen(output_filename, "w");
    if (output_file == NULL) {
        free(data);
        printf("Error: Could not open file %s\n", output_filename);
        return EXIT_FAILURE;
    }
    // ...

    // ...
```

### Lettura dal file

La lettura dei numeri da file implica necessariamente una struttura di memorizzazione dinamica, in quanto non si conosce a priori il numero di numeri presenti nel file. Per questo motivo, si utilizza un array dinamico che viene ridimensionato ogni volta che si raggiunge la capacità massima.

Per leggere un singolo numero dal file, dovremo utilizzare un ciclo `while`. Il ciclo `while` dovrà leggere fino a quando una determinata condizione non è più verificata. La più basilare sarebbe quella di utilizzare `true` come condizione e all'interno del body svolgere il costrutto *Read-Check-Use*. Tuttavia, in questo caso, è possibile utilizzare direttamente la funzione `fscanf` come condizione del ciclo.

```c
// ...

int main(int argc, char **argv) {
    // ...

    size_t size = 0;
    size_t capacity = 0;
    int32_t *data = NULL;

    int32_t number;
    while (fscanf(input_file, "%d", &number) == 1) {
        if (size >= capacity) {
            size_t temp_capacity = capacity == 0 ? 1 : capacity * 2;
            int32_t *temp_data = realloc(data, temp_capacity * sizeof(int32_t));
            data = temp_data;
            capacity = temp_capacity;
        }
        data[size] = number;
        size++;
    }

    // ...
}
```

Infatti, `fscanf` con il pattern `"%d"` inizia a leggere dal file un carattere alla volta fino a quando non incontra un carattere che non può essere interpretato come numero. In quel momento, `fscanf` restituisce il numero di elementi letti con successo, che in questo caso sarà 1 se è stato letto un numero e 0 se non è stato letto nulla. In caso di errore, `fscanf` non restituisce più 1, quindi il ciclo termina. In questo modo abbiamo implementato il costrutto *Read-Check-Use* in maniera più elegante.

All'interno del body del ciclo, viene controllato se la dimensione dell'array è maggiore o uguale alla capacità. In tal caso, l'array viene ridimensionato raddoppiando la sua capacità. Infine, il numero appena letto viene memorizzato nell'array e la dimensione viene incrementata. In questo modo siamo in grado di leggere un numero indefinito di numeri da file e memorizzarli in un array dinamico.

### Ordinamento dei numeri

L'ordinamento dell'array `data` può essere effettuato utilizzando la funzione `qsort` della libreria standard C. La funzione `qsort` richiede quattro parametri, un puntatore all'array da ordinare, il numero di elementi nell'array, la dimensione di ciascun elemento e un puntatore a una funzione di confronto.

```c
int compare_int32(const void *pointer_a, const void *pointer_b) {
    int32_t number_a = *(int32_t *)pointer_a;
    int32_t number_b = *(int32_t *)pointer_b;
    return (number_a > number_b) - (number_a < number_b);
}

int main(int argc, char **argv) {
    // ...

    qsort(data, size, sizeof(int32_t), compare_int32);

    // ...
}
```

La funzione di confronto `compare_int32` è stata implementate secondo le specifiche della funzione `qsort`. Essa prende due puntatori a `void` come parametri, li converte in puntatori a `int32_t`, dereferenzia i puntatori per ottenere i valori interi e restituisce un valore intero che indica l'ordine dei due numeri. In particolare, la funzione restituisce un numero negativo se il primo numero è minore del secondo, zero se sono uguali e un numero positivo se il primo numero è maggiore del secondo.

### Scrittura sul file

Il programma termina scrivendo i numeri ordinati nel file di output. Per fare ciò, viene utilizzato un ciclo `for` che itera su tutti gli elementi dell'array `data` e li scrive nel file di output utilizzando la funzione `fprintf`. Infine, il file di output viene chiuso e la memoria allocata per l'array dinamico viene liberata.

```c
// ...

int main(int argc, char **argv) {
    // ...

    for (size_t index = 0; index < size; index++) {
        fprintf(output_file, "%d\n", data[index]);
    }
    fclose(output_file);

    free(data);
    return EXIT_SUCCESS;
}
```
