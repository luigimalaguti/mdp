# Split

> **Multimedia data processing**
>
> Data: *2026-04-27*

Write a program that accepts the following syntax:

```bash
split <filename.pam>
```

The program opens a color PAM image whose name is given as argument on the command line file and saves three grayscale PAM images named "filename_R.pam", "filename_G.pam" and "filename_B.pam", containing the separate R, G and B color planes. You can verify that the images are correctly saved by opening them with XnView.
