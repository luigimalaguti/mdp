# Combine

> **Multimedia data processing**
>
> Data: *2026-04-27*

Write a program that accepts the following syntax:

```bash
combine <filename>
```

The program opens the three files "filename_R.pam", "filename_G.pam" and "filename_B.pam", containing three separate R, G and B color planes, and generates the file "filename_reconstructed.pam" composed by combining the three color planes in a single RGB image. You can verify that the output image is correct by opening it with XnView.
